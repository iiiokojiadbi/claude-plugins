# claude-plugins

A Claude Code plugin marketplace. Each plugin lives in its own repository; this one only lists them.

```
claude plugin marketplace add iiiokojiadbi/claude-plugins
claude plugin install <plugin>@iiiokojiadbi
```

| Plugin | What it does |
|---|---|
| [shift](https://github.com/iiiokojiadbi/shift) | The agent shifts itself at a stage boundary: keeps strict work records, writes itself a letter, steers the compaction and continues where it stopped |
| [herdr-orchestrator](https://github.com/iiiokojiadbi/herdr-setup) | Native tools for the lead agent to start, task, wait on, read and stop herdr workers |
| [herdr-worker](https://github.com/iiiokojiadbi/herdr-setup) | Reports results and blockers from a herdr worker to its parent agent |
