# claude-plugins

A Claude Code plugin marketplace. Each plugin lives in its own repository; this one only lists them.

```
claude plugin marketplace add iiiokojiadbi/claude-plugins
claude plugin install <plugin>@iiiokojiadbi
```

| Plugin | What it does |
|---|---|
| [infinity-shift](https://github.com/iiiokojiadbi/infinity-shift) | The agent shifts itself at a stage boundary: keeps strict work records, writes itself a letter, steers the compaction and continues where it stopped |
